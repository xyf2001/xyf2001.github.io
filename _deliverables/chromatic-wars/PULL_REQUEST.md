# 颜色大战1.5.3：专用GPU管线、并行前缀查询和完整配置诊断

目标 `xyf2001/xyf2001.github.io:master`。现有PR：[xyf2001/xyf2001.github.io#1](https://github.com/xyf2001/xyf2001.github.io/pull/1)。此文件描述当前可审阅实现。

用户在9800X3D/RTX5080、2067活跃、10000容量、1024²领土和1536²画面、关闭己方碰撞时，反馈1.5.2只有4FPS、GPU批次约174ms。源码显示此前新增首接触pass由单个GPU invocation对所有活跃粒子重新查询邻域，再执行原九色碰撞；并且移动、染地和绘制共用动态模式管线。

本版以specialization constant建立mode0至14的专用管线，保留同一资源布局及屏障。首接触查询按GPU活跃表间接并行，每线程只写自身的时间/限制候选记录；随后的单写者按原顺序执行领土与整数付款，限制候选已死亡时重新查询。整个胶囊AABB为己方时省去精确扫描；能量严格大于AABB格数上界时精确单扫描，其余段保留耗尽TOI排序，去掉未满工作批后的复扫。前缀缓冲为每实体8字节加16字节摘要，所有专用管线统一释放。未减少碰撞、粒子数或分辨率。

右侧新增“复制完整诊断与配置”，只在用户点击时汇总版本、硬件、原有遥测、全部设置、开局/已提交/待重开差异及CPU当前物理布局。主线程提交配置不冒充GPU确认；不读取渲染线程私有字典、不增加读回或自动上传。默认时间倍率为真正1×，旧无迁移标记的0.25×配置一次迁移，之后手动慢速仍保留；配置测试中的旧默认期望同步更新但未运行。

此前的连续有限半径染地、每格1整数能量、狙击宽度与主次尾迹、保命补盾及UI、机枪小角扫射/10模拟秒弹匣、友方碰撞开关、16球弹球机、风暴与布局编辑保留。首接触仍不是所有后续碰撞链的全局CCD排序，串行付款和实体事件仍限制吞吐。

本轮继续按用户要求**不启动游戏或测试**。仅资源导入与Windows导出构建，实际日志/状态和用户原始遥测存于 `chromatic-wars/artifacts/build-1.5.3-no-tests/`，新包明确NOT TESTED。用户反馈不是云端基准；没有新版实际FPS、阶段占比、寄存器spill或实体驱动验收，不宣称性能百分比/60FPS。旧版构建和测试保留在原检查点，不用于证明本版通过。

完整源码在 `chromatic-wars/`；新Windows/源码ZIP、哈希和交付清单在 `_deliverables/chromatic-wars/`，旧下载保留供回退。详细算法、风险、配置复制字段与迁移边界见工程内 `docs/GPU管线1.5.3.md`、`TEST_REPORT.md` 和 `CHANGELOG.md`。
