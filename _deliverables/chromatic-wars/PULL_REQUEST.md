# 颜色大战1.5.2：连续染地、狙击宽度、保命和机枪瞄准修正

目标 `xyf2001/xyf2001.github.io:master`。现有PR：[xyf2001/xyf2001.github.io#1](https://github.com/xyf2001/xyf2001.github.io/pull/1)。此文件是当前实现的审阅说明。

粒子原有的领土查询可能遗漏真实半径扫过的格子。现在按运动圆盘与格矩形的严格正面积交叠、首次进入时间顺序结算，每个实际改变归属的格子仍扣1整数能量。首接触前缀在粒子抵消前先支付碰前领土，后续事件跳过已付前缀。真实弹道之间仍会有空隙，后续多实体碰撞链仍非全局CCD排序。

狙击弹物理半径随剩余实际能量单调且有界增长，分裂后父子分别更新宽度。主弹白芯长尾、次级阵营色短尾，均为有限飞行弹丸。新增独立32单位宽弹网格，普通粒子保留九色空间布局；高速弹保留完整回退，不截断候选或重复结算同一配对。

紧急保命原先补盾后马上申请扩张，少量救援能量可能在同一prepare被领土染色耗尽。现在救援补盾不立即扩张并取消旧扩张游标，保留原能量、180模拟秒冷却和真实攻击；UI显示请求、成功、无球失败或冷却内再次被击破。没有新增无敌或额外能量。

机枪失效威胁立即解除锁定，补地不再永久固定朝向一格，锁定和补地逐发加入极小角度扇扫。固定射速、每次补弹把全部剩余库存均匀分配到10模拟秒、整数商余及0.5模拟秒有效目标切换CD保留。无有效威胁时恢复连续旋转，避免长串同角度造成变相狙击。

此前的整数高能粒子、友方真实碰撞与开关、大球部分磨损、最多3圈风暴、三级狙击、护盾扩张、16球弹球机及固定柱编辑保留。没有随时间增长的发射成本，染格每格1能量。70%/30%对象仍待确认，保留现有父子拆分，不把整数守恒等同于玩法语义已确认。

本轮依用户要求**不运行游戏或测试**。仅资源导入与Windows导出构建，日志和实际退出状态在 `chromatic-wars/artifacts/build-1.5.2-no-tests/`，新包明确标记NOT TESTED。1.5.1及更早规则、软件Vulkan性能和长局记录保留为历史，不用于证明本版通过。新增串行前缀查询、空间缓冲的耗时及复杂碰撞正确性没有本版运行验证；不宣称优化百分比、Windows或RTX5060Ti表现。
