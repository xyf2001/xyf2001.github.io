# 颜色大战1.5.1：高能粒子、10秒机枪分配与GPU活跃调度

目标：`xyf2001/xyf2001.github.io:master`。现有PR：[xyf2001/xyf2001.github.io#1](https://github.com/xyf2001/xyf2001.github.io/pull/1)。本文件提供与最终实现一致的审阅说明。

大粒子池原先会对大量空槽反复执行运动、空间构建和串行事件，增加容量本身就会拖慢模拟。本次引入稳定物理ID、GPU常驻活跃表/空闲栈和间接dispatch，使常规工作量主要跟随实际活跃数。保留完整空间邻域、九色唯一配对、高速回退和真实友方碰撞，没有通过降低分辨率或减少玩法掩盖负载。

取消随时间增长的发射成本。所有粒子与大球每次实际染格只扣1能量，余能继续；普通高能弹按真实墙和实体TOI逐段先结算地形。机枪固定高射速，每次真实补弹把剩余库存加新输入均匀分配到接下来10模拟秒的射击槽，更多弹药带来更强单发，整数余数均匀分散；补弹不重置射击相位或瞄准。

敌粒子以64位整数等量抵消，友方普通粒子碰撞不耗能；大球的反弹与部分磨损使用碰前质量。狙击使用最近TOI顺序及三级70/30整数分裂，普通粒子不改变其方向，满池延期不丢能。风暴最多3个360整圈，商余完整分配。护盾尺寸不再随世界基准自动缩小，充能按核心向外逐格染色，每格支付1能量。

按后续明确参数，机枪目标切换CD默认0.5模拟秒，有效原目标不被更高评分提前抢占，失效立即重选；同槽重生通过代号区别目标身份。旧版本没有70/30双向分配依据，当前开发稿的父/子分配暂保留并明确列为对象待确认；整数测试只证明当前实现守恒。

左侧保留16球、数值2出生和出生基准锁定；采用相对增长率递减的指数门槛，修复默认柱壁楔死及防卡确认期末误重发。预设与自定义固定柱均可编辑保存。另修复死队到期命令能量漏账、已释放旧世界退役节点未移除，以及面板库存整数尾数损失。

新规则的实际回归、主场景、性能、长局及最终导出结果详见[实际测试报告](../../chromatic-wars/TEST_REPORT.md)。测试覆盖1000–100000活跃、相同活跃数不同容量、非空密集交汇、1000狙击真实墙分裂、10秒完整机枪分配、补弹重规划、大整数商余、稀疏槽与连续染格。左侧未改动的物理另有三种子累计4200模拟秒记录。原始失败、用户规则更新引起的中断和性能回退证据均保留，不用旧成本构建的结果冒充新规则通过。

所有GPU实测均为llvmpipe软件Vulkan，不代表RTX5060Ti。容量与活跃数的同条件对照、阶段及等待数据在报告中，不保证全场景提速。物理池背压或人工停火会延长名义10秒；能量少于射击槽时有稀疏空槽，不能凭空生成能量。高密真实碰撞和串行事件仍有限制；Windows实体系统、物理显存和RTX帧率未测。
