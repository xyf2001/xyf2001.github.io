# 颜色大战1.5.4：非空碰撞调度、快速救援和人工战场控制

目标 `xyf2001/xyf2001.github.io:master`，现有PR：[仓库#1](https://github.com/xyf2001/xyf2001.github.io/pull/1)。

用户反馈RTX5080低活跃粒子下仍明显卡顿，紧急保命来不及补盾。本版将九色碰撞从全128²网格中心改为GPU构建的非空普通格列表与9组间接调度；保留原3×3候选、去重和颜色屏障。增加无实体接触段的保守筛选，非耗尽胶囊染地使用精确布尔相交而不求TOI；延迟退化速度方向计算，批量上传连续命令。没有降低分辨率、粒子数、物理子步或关闭真实碰撞。串行领土及实体付款仍有吞吐限制。

保命请求独立于0.25现实秒UI读回，收到后通过专用prepare立即提交补盾，不重放普通武器。状态序号/nonce/代数隔离旧回调；新增真实护盾防御储备，后续扩张只能花非储备能量，实际伤害仍正常扣账。没有新增无敌时间；GPU已有工作与CPU取球仍有延迟。

新增1～4队新局：每队4左球、初始领土随队数划分、未参战队停用。新增明确的人工调试控制：指定参战队和武器输入一次十进制正int64能量（全过程不经float），以及暂停可用的真实领土画笔。画笔mode15每格唯一写者，仅修改owner和面积统计，不推进模拟或触发武器。独立命令槽、队列限额和每帧插值限制控制编辑开销。原有固定柱增删权限保留。

新增手动GPU阶段采集按钮，默认关闭，只采样下一批首个微步与最终绘制；阶段覆盖、未采样部分、缺失计时与批次身份保留在完整诊断中，不伪称全批阶段占比或同步等待时间。

本轮按用户“修改但不测试”要求，**只资源导入与Windows导出构建，不运行游戏、规则/性能/长局或内嵌PCK测试**。实际构建状态、日志与源码/EXE哈希位于 `chromatic-wars/artifacts/build-1.5.4-no-tests/`，新包标NOT TESTED。没有本版实体显卡或Windows验收数据，不宣称优化比例/60FPS；历史证据保留原检查点。完整说明见工程README、CHANGELOG、TEST_REPORT及 `docs/性能与救援1.5.4.md`。
