# 颜色大战 · 1.4.2-motion

- [Windows版下载](ChromaticWars-Windows-x64-Motion.zip)：解压后运行`颜色大战.exe`。
- [Godot源码下载](ChromaticWars-Godot-Source-Motion.zip)：Godot 4.6.3可编辑工程。

针对停弹、角落挤压和大球停住：

- 普通粒子碰撞改变方向，但保持各自出生速率；原先等质量碰撞只守恒总动能，能使单颗速度降到零。
- 普通粒子与大球的位置投影后补墙约束，反射朝外的运动，防止被挤出边界后反复夹回。
- 大球增加最低移速，默认40px/s，可在参数中即时调整且不超过发射速度；保留有效方向，精确停住时采用最近航向，不增加弹药能量。

普通粒子仍一粒染一格；停滞会减少到达前线的粒子，但512²格子较小与成本增长也会使占地较慢。保留固定1200基础机枪、逐圈风暴、狙击只取消粒子偏转、大球部分消耗/吸收、左侧防卡和预设固定柱编辑。

按用户要求，本次未运行游戏、规则/交互/性能或PCK运行测试；仅源码静态审阅、资源导入、Windows导出与打包。最低速度可以防止速度衰减到零，不是任何密集布局都无拥挤的实测保证。详见包内`docs/恒速与最低移速修复.md`和`TEST_REPORT.md`；历史PASS不代表此版本。旧版文件保留供回退。
