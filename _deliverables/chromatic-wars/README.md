# 颜色大战 · 1.3.0-sandbox 聚能弹与布局编辑版

- `ChromaticWars-Windows-x64-Sandbox.zip`：解压后运行`颜色大战.exe`。
- `ChromaticWars-Godot-Source-Sandbox.zip`：Godot 4.6.3可编辑工程。

狙击蓄能后发射单颗真正飞行的高能弹，带白热短拖尾，可调弹速和充能时间。同阵营粒子/大球互相穿过；每格按阵营分链，避免同阵营候选的无效遍历。

「参数设置」新增：
- 固定柱编辑开关，自动暂停；收起面板后左键放柱、右键删除自定义柱，自动保存，最多64根。
- ×8/×4/×2通道净宽，左右对称，中央保留至少84px，底墙同步调整。
- 四阵营基地XY坐标，新开局生效；护盾最大宽度（直径）。
- 应用流畅预设并新开局：256²领土、512²画面、关闭普通拖尾，保留精确模式与全部粒子显示。

按用户要求本轮未运行游戏/交互/性能测试，仅修改、构建与打包。未测具体FPS提升，历史测试不代表当前版本。详细说明在包内README.md及docs/聚能弹与布局编辑.md。
