# 颜色大战 · 1.4.3-air-aim

- [Windows版下载](ChromaticWars-Windows-x64-Air-Aim.zip)：解压后运行`颜色大战.exe`。
- [Godot源码下载](ChromaticWars-Godot-Source-Air-Aim.zip)：Godot 4.6.3可编辑工程。

本版修改：

- 修复后期小球按初始门槛计算质量而变得过重的问题；质量主要随自身出生门槛下的成长变化，空气墙覆盖球体边缘并增加小球下冲阻力。保留每球锁定门槛，正常输出后重置为2。
- 机枪取消角度保持，每个有弹药的模拟子步重新索敌；采用空间建桶时的并行威胁摘要，保留连续逐发角度与有限转向速度。
- 防卡缩短为静止观察3、局部循环观察8、持续确认0.4、重发冷却1模拟秒，保留弹药/阵营/出生门槛，不触发输出或倍率。
- 所有物理长度、坐标、半径、宽度统一使用游戏单位；速度及加速度按模拟秒。渲染分辨率标像素，领土精度标格数，FPS和GPU耗时保持真实设备含义。
- 参数设置 →「04 GPU性能与画面」新增「同阵营普通粒子碰撞」实时开关，默认开启，支持保存和加载。大球之间碰撞、己方粒子补大球、敌方抵消和狙击规则照常。

保留普通粒子恒速、大球最低移速、固定1200基础机枪、逐圈风暴和预设固定柱编辑。未降低分辨率。空气墙为有限推力，不能保证任意极端碰撞或自定义参数下小球永不穿过；早期出生且已长大的低数值球仍可合法输出。

按用户要求，本次未运行游戏、规则/交互/性能或PCK运行测试；仅源码静态审阅、资源导入、Windows导出与打包。详见包内`docs/空气墙与即时索敌.md`和`TEST_REPORT.md`；历史PASS不代表此版本，不承诺具体FPS收益。旧版文件保留供回退。
