# 颜色大战 · 1.4.0-physics-rings

- [Windows版下载](ChromaticWars-Windows-x64-Physics-Rings.zip)：解压后运行`颜色大战.exe`。
- [Godot源码下载](ChromaticWars-Godot-Source-Physics-Rings.zip)：Godot 4.6.3可编辑工程。

风暴改为逐圈发射，输入越多发射圈数越多；每颗普通粒子按实际发射时的时间成本扣弹药，能量锁定，一粒只染一格。同色粒子恢复实体碰撞，敌方普通粒子一对一互消。机枪连续多方向发射，优先附近领土，自动识别来袭大球、粒子和聚能弹并临时提高射速。狙击保留飞行聚能弹。

大球按有界质量/软硬反弹与部分消耗，吸收己方粒子的真实能量，粒子命中推动按整步实际能量汇总。左侧加入数值与体积共同决定的质量、弹性、空气响应及保值防卡。大球粗空间索引筛除远距离候选；流畅预设保留分辨率、地图精度、可视密度与拖尾。

固定柱权限：参数→编辑固定柱，收起面板后左键添加、右键删除预设或自定义柱；支持恢复预设、清空全部、自动保存。恢复预设时保留自定义柱，重叠位置暂不恢复；改柱不重置球。

按用户要求，本轮未运行游戏、交互测试、规则测试或性能测量；只做源码审阅、资源导入、Windows导出与打包。平衡数值尚待实机微调，没有实测FPS承诺。详见包内`docs/物理与环形风暴.md`与`TEST_REPORT.md`，历史PASS不代表此版本。

旧版Sandbox文件保留供回退。
