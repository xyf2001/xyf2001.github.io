# 颜色大战 · 1.4.1-continuous-gun

- [Windows版下载](ChromaticWars-Windows-x64-Continuous-Gun.zip)：解压后运行`颜色大战.exe`。
- [Godot源码下载](ChromaticWars-Godot-Source-Continuous-Gun.zip)：Godot 4.6.3可编辑工程。

本版修改：

- 机枪默认固定1200颗/模拟秒，不再随进程提高射速；参数内可调固定射速和旋转速度。逐发计算子步内出生时刻、连续炮口角度和首步飞行时长，删除扇形散射、阻塞后的整发集中补发。补地、防守时平滑转向，临时威胁加速保留。
- 狙击弹仅取消与粒子的物理碰撞：友方粒子穿过，敌方粒子仍等量抵消能量，不改变双方位置或速度。与大球、护盾、墙壁的其他交互保留。
- 狙击弹和大球每占领一格按占领时的当前普通粒子成本扣能；不足一格时消耗余量，不免费染格。普通粒子仍一粒染一格。

风暴分圈、同色普通粒子实体碰撞、大球吸收与部分互耗、左侧防卡、预设固定柱删除/恢复/自动保存均保留。没有降低分辨率或视觉密度。

按用户要求，本次未运行游戏、规则/交互/性能或PCK运行测试；仅源码静态审阅、资源导入、Windows导出和打包。实际弹幕观感及FPS未经实机验证，密集同色实体碰撞仍可能使卷曲轨迹变形。详见包内`docs/连续机枪与占地成本.md`和`TEST_REPORT.md`；历史PASS不代表本版。

旧版Physics-Rings及Sandbox文件保留供回退。
