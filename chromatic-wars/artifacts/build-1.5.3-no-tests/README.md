# 1.5.3 构建与用户反馈记录

`build_metadata.json`记录本版资源导入及Windows导出实际命令、退出码、构建前后运行源码SHA256和导出EXE哈希。`import.log`、`export.log`是原始构建输出。导入缓存对应当前Shader；构建没有启动游戏。

用户要求修改但不测试，本版没有CPU/GPU规则、配置迁移/剪贴板、性能、长局或内嵌PCK运行结果。专用Compute管线的实际驱动创建和执行也未验证。编辑器资源导入使用Linux软件Vulkan，这不是RTX5080的性能数据。

`user_telemetry_1.5.2.json`为用户手动提供的旧版实机诊断，附明确来源和计时范围，未经云端复测。它不能与未运行的1.5.3形成前后基准，也不能用于宣称优化比例。
