# 真实风暴性能诊断对比

软件 Vulkan (llvmpipe)，正常 Forward+ 窗口。原版与最终版都通过正式 `output(team, storm, 100000)` 发射四队风暴，保留默认 1 万容量、512² 领土、768² 画面与精确粒子模式，没有使用均匀注入。均经 26 个固定步实际达到 10000 活跃粒子，然后采样 3 次。

每次采样推进一个 1/120 秒固定步、实际两个 GPU 子步。为取得阶段时间戳，诊断版在采样阶段把各 dispatch 拆为独立 compute list；这会改变调度成本。墙钟还包含小表异步快照和时间戳等待。因此以下数字不是原游戏 FPS，也不是 RTX 5060 Ti 的性能实测。

| 测量中位数 | 原版 | 最终版 |
| --- | ---: | ---: |
| 九色碰撞 GPU 时间 | 244.620 ms | 49.673 ms |
| 领土/护盾/大球事件 GPU 时间 | 34.904 ms | 6.397 ms |
| 统计 GPU 时间 | 6.276 ms | 0.739 ms |
| 发射准备 GPU 时间 | 4.634 ms | 1.020 ms |
| 画面计算 GPU 时间 | 16.618 ms | 21.051 ms |
| 墙钟（含快照/时间戳等待） | 420.010 ms | 150.188 ms |

原版三次墙钟为 402.256 / 505.206 / 420.010 ms，最终版为 89.844 / 150.188 / 226.328 ms，软件 Vulkan 存在明显抖动。仅凭这 3 次短采样不能保证用户原机帧率。

两版所有样本保持 10000 活跃粒子、总能量 8400000 守恒、溢出 0。原版 16px 格最大占用 56；最终版 8px 格最大占用 17。格面积不同，这两个占用数字只作诊断，不直接用于计算性能提升比例。

最终版减小空间桶、压紧每相位中心格调度，并配套更严格的半径/速度子步上限，仍保留九色依赖与粒子对单次结算。真实游戏不同种子、多轮高能风暴、极端碰撞后超配置速度，以及 RTX 5060 Ti 原机表现仍需验证。

原始证据：`storm_profile_before.log/.json`、`storm_profile_final.log/.json`。可复现工具为 `tools/storm_profile.gd`；数据汇总为 `storm_profile_final_summary.json`。
