# GPU 架构与精度

右侧正式路径使用 `RenderingServer.get_rendering_device()` 的主 RenderingDevice，在渲染线程创建、运行、读回和释放资源。`Texture2DRD` 共享 RGBA8 输出纹理给 Godot 画布；没有本地 RD、`submit()/sync()`、整帧 GPU→CPU→GPU 绘制或 CPU 战场粒子遍历。

## 模块及缓冲布局

`GPUWorld` 管生命周期、固定步批处理、参数和小表异步统计；`GPUEmitters` 编码左侧真实输出；`GPUCollisions` 计算安全子步；`GPURender` 创建共享输出。模拟内核位于 `shaders/battle.glsl`。

## 活跃数量与每步依赖

普通发射从GPU空闲栈O(1)取槽并追加活跃ID。能量归零立即令类型为0，后续物理跳过；事件结束后按GPU死亡dirty决定是否稳定压紧并一次性回收；无死亡只刷新间接参数。压紧不移动物理ID；空槽重用可以改变后续访问顺序。

每个固定子步依次执行：命令及发射 → mode11更新间接参数 → 活跃实体运动 → 清网格 → 活跃粒子建桶 → 九色邻格碰撞 → 串行大球/盾核/领土事件及狙击分裂 → mode12回收并更新间接参数。运动、建桶和粒子绘制调用 `compute_list_dispatch_indirect`；事件、高速回退和低频统计也按活跃ID遍历。初始化、显式调试填充和显存申请仍与最大容量有关，正常每步不再遍历整个普通粒子池。

批末清像素、绘制粒子/大球、合成地图及核心护盾。地图/输出像素pass仍按地图/输出尺寸调度，空间桶清理仍按固定网格调度；活跃索引不降低分辨率。间接屏障、复杂度及验证记录见[GPU活跃粒子索引](GPU活跃粒子索引.md)。

每次dispatch有compute barrier。九色中心格的3×3静态链表写集合互不重叠，一个invocation处理一个中心格，粒子对按唯一物理ID排序只结算一次；跨色屏障隔开写入。链表不截断前32/64颗。超出安全位移的粒子进入高速链，在事件阶段与实际活跃ID完整补查，不夹速或漏查。大球用独立64槽、存活位图及4×4粗网格处理。

安全子步满足 `dt ≤ 1/120` 且位移上界为 `min(4, (8 - 2 × 普通半径) / 2)` 游戏单位。正式默认半径1.2、狙击速度620时，一个1/120模拟秒固定步细分为两个GPU子步。高速回退仍覆盖旧弹速度或特殊注入超过当前配置的情况。

## 当前整数能量与领土规则

普通粒子能量由发射时的武器成本与整数分配决定，不固定为1。机枪在补弹时锁定单发能量；风暴在事件开始时将输入整数分配到最多三圈；不足机枪整发的库存尾数可作为末发。旧粒子不追溯成本。保留的 `precision_mode`、`packet_energy` 兼容参数不代表当前存在另一套“近似能量包”物理。

敌方普通/狙击粒子按双方能量的min等量抵消，幸存者不因抵消改变方向；狙击不受普通粒子的实体反弹。同阵营普通粒子在开关开启时真实碰撞而不扣能，关闭时穿过。己方粒子补大球，敌方粒子与大球等消；大球之间及撞盾按接触前机械状态求反弹与部分损耗，损耗不会反推为额外速度。整数风暴分配与狙击70%/30%分裂见[武器整数结算与默认分裂](武器整数结算与默认分裂.md)。

普通粒子首次改变一个非己方格子时消耗全部剩余能量，只染一格，己方格免费。狙击/大球每次真实改变归属扣当时的普通粒子成本，不足则耗尽而不染该格。护盾扩张另按从核心向外的游标染色，每个实际改变的格子扣1护盾能量。普通/狙击轨迹用DDA，大球扫掠胶囊按格子中心覆盖；先结算实体接触之前的领土路径，不能越过本应耗尽的敌地伤盾或补球。

GPU能量使用两个uint执行整数加减、比较、分配和进位，累计上限为 **2^63−1**。CPU正式输出接口使用double，单笔精确整数范围为 **0..2^53−1**；左侧超限时明确暂停。浮点用于运动、半径/质量等映射和紧凑显示。GPU累计超限置错误位并停止模拟，不能把饱和数值当作守恒通过。

普通池、大球槽或命令环满时，未发能量保留库存或队列。普通空闲分配不再扫描容量；大球分配只查最多64槽且缓存当次满载。命令环连续前缀回收和独立充能优先区保留，不保证不同倍速批次的排队时间或轨迹逐位一致。

## 遥测、生命周期与限制

正式每约0.25真实秒读取统计256B、四队512B、大球4096B及诊断128B，共4992B。普通粒子全表、领土整图和输出纹理不进入正式读回。Godot4.4+使用异步API；4.3兼容分支只对小表低频同步读取，并单独记录显式阻塞耗时。

`gpu_profiling=true`才额外统计候选/接触，默认关闭。累计uint32短窗差值须处理回卷。GPU timestamp纳秒转毫秒；CPU提交、显式同步读回和异步完成延迟分别报告。申请的缓冲/纹理字节数不等于驱动完整显存；分阶段工具拆列表的时间不能直接当正式帧率。

关闭或重开先停止旧代工作并断开显示纹理，等已登记读回归还后才在渲染线程释放RD资源；主场景等 `is_shutdown_complete()` 后销毁退役节点。同对象仍有读回或释放未完成时，`start()`拒绝重用。详见[GPU状态与同步](GPU状态与同步.md)。

串行事件和发生死亡时的稳定压紧仍随实际活跃数增长；大球交互最坏O(A×B+B²)，B≤64；高速回退最坏O(F×A)，密集桶局部仍可O(k²)。高容量不承诺60FPS，软件Vulkan数据不代表RTX 5060 Ti。实机性能和长局完成范围以真实测试记录为准。

开发目录动态编译当前GLSL；导出PCK可加载Godot导入SPIR-V，Windows导出前须完整导入。资源创建、绑定或编译失败显示真实错误，不切换CPU战场。
