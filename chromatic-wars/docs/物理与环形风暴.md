# 物理与环形风暴：当前1.5.1与历史1.4.0

## 当前1.5.1实现与证据

- 已删除随进程增长的发射成本及旧配置入口。粒子携带真实整数能量，敌方粒子按能量最小值等量抵消，幸存方向不变；友方普通粒子实体碰撞不耗能。每改变一个非己方领土格扣1能量，余能继续。
- 风暴最多3圈，每整圈360颗，完成后的圈间隔默认0.10模拟秒。输入不足360时可为较稀疏的一圈，不生成零能量实体；全部输入按实际发射粒子数整数商余分配，池满保留角序与库存。
- 机枪默认固定1200射击槽/模拟秒，不随时间或威胁临时加速。每次真实补弹将剩余库存加新输入按默认10模拟秒均匀分摊；正射速与时长下次补弹锁定。保留连续相位、炮口和目标，0.5模拟秒有效目标锁，失效立即重选；低能稀疏槽、调试停火与满池背压边界见[连续机枪说明](连续机枪与占地成本.md)。
- 大球碰撞按碰前质量/软硬/法向速度求机械反应与部分损耗，粒子推动也使用接触前质量；最低速由移动前独立有限加速度驱动。友方粒子馈能后消失，不将扣能后的较小质量用于放大原冲量。
- 常规移动、建桶和绘制按GPU常驻活跃ID间接调度，不再因空池最大容量增加而逐槽执行这些工作。空间格九色去重及高速完整回退仍保留；容量相关初始化、分配内存与64个大球槽的固定工作仍有成本。真实密集桶候选和串行领土/盾/实体事件仍昂贵。
- 左侧出生仍为2并锁定当时门槛；门槛现为相对增速渐缓的指数曲线，倍率和保值重发不更新出生基准。防卡现按0.1模拟秒采样、3秒静止/8秒局部循环、0.4秒确认、1秒重发冷却，默认固定柱仍可增删；入口双支点桥接与任意自定义堵塞并未全部消除。

当前c8实际规则结果为140项武器/GPU、32项接触、13,076项池断言（114观测）、47项设置和20项墙断言；[汇总](../artifacts/validation-1.5.1/rules-area-guard/SUMMARY.json)保存范围及证据。另已完成[44次性能场景](../artifacts/validation-1.5.1/performance-area-guard/SUMMARY.json)、主场景10项与导出/PCK实跑，当前完整长局仍须独立完成，不由短测替代。

所有GPU记录来自llvmpipe软件Vulkan，不是RTX 5060 Ti或Windows原生结果。固定活跃数的当前容量对照支持空扫描成本降低，但1,000活跃小池仍有退步，四方风暴也未因全己色快路径提速；不能承诺所有设置60FPS。地图512²/显示768²的正式比较没有降分辨率，用户目标高分辨率仍需实机验收。数据及口径见[性能验证](性能验证1.5.md)。

## 历史1.4.0记录

以下均是当时1.4.0规则，不是当前默认或当前验收结论。该版本按当时用户要求未运行游戏、规则测试、性能测试或PCK运行验证，资源导入与Windows导出仅为构建步骤。时间成本、96颗风暴、增长射速、线性门槛与旧防卡窗口已被后续版本替代。

- 普通粒子成本：`1 + floor(max(t-60,0)*0.25)`，t为模拟秒；在发射时锁定，库存不足保留余数。一粒首次染到非己方格子即耗尽；同色碰撞只改变运动，敌方普通粒子一对一消失，各扣其完整能量。
- 风暴：默认96颗一圈、圈间隔0.10模拟秒；小库存按可支付粒子数均匀分配一圈，大库存持续更多圈。生成预算或槽位不足则保留角序；若暂停中的圈跨过成本增长节点，剩余库存不足下一颗会继续等待，不透支也不生成低能尾弹。
- 机枪：默认120→1400真实粒子/模拟秒，连续扇形分散；80ms缓存刷新附近领土缺口和来袭大球/普通粒子/聚能弹，受威胁时最高1.8倍射速，库存与容量限制始终生效。旧默认42射速配置自动迁移为120，自定义射速保留。
- 右侧大球机械质量由半径平方与有界对数能量组成，恢复系数随尺寸与能量降低。同阵营大球实体碰撞不耗能；异阵营新接触按速度、质量差及硬度差消耗一部分双方能量，绝对消耗相等；相近大球缓慢接触不会凭空猛烈弹开。
- 己方普通粒子将全部出生能量转给大球并消失，敌方普通粒子按实际能量削减大球；大球推动在同一步按真实能量和方向汇总，再按最终有效质量计算速度变化，并用300单位/秒²的平滑加速度界限避免极大数值产生异常速度。
- 右侧普通邻域保留8px格、九色串行依赖和唯一碰撞对；弹性加速造成的快速粒子使用独立链完整查询。大球用4×4粗网格筛选候选，吸收增大半径后立即增加索引覆盖。没有降低渲染/领土分辨率、删除同色碰撞或截断候选数量。
- 左侧所有阵营保持实体碰撞。有效质量为最小球基准质量乘`1+24*尺寸因子+8*弹药因子`，弹药因子为有界对数；恢复系数和空气响应也考虑这两个因子，弹药账本不参与浮点机械冲量求和。
- 左侧体积门槛在1200模拟秒后继续线性提高；每次正常出生数值2并锁定门槛，倍率及防卡重发保持原门槛。原有紧急护盾救援仍会提取一球补盾并正常重新出生。
- 防卡按每球0.15模拟秒采样，观察8秒低运动或24秒局部循环，加1.2秒确认与发射冷却。真实子步路程用于排除采样混叠。保值重发不触发输出/倍率/武器；合法倍率循环不作为强制能量封顶。出生区被编辑柱完全堵住时保留球等待，布局解除阻塞后重发。
- 预设15柱和自定义柱均可右键删除并保存；恢复预设时保留自定义柱，重叠位置不强行恢复。清空全部会移除两类柱。开编辑模式自动暂停，改柱不重置球。

1.4.0当时未实测RTX 5060 Ti帧率和平衡参数，当时仍有按最大容量调度的开销；该调度描述仅属历史。当前按活跃ID调度的验证及剩余成本见上节，历史测试只属于其明确版本。
