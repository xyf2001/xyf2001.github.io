# 连续机枪与占地能量：当前1.5.1与历史1.4.1

## 当前1.5.1规则

机枪默认固定1200射击槽/模拟秒、旋转1.7弧度/模拟秒；不随游戏时间增长，也不因防守临时提高射频。每发保留独立的子步内出生时刻与出生后运动时长，实际友方碰撞仍可改变弹幕形状，不能保证在密集战斗中保持理想螺旋。

每次真实补弹以“剩余库存+新入能量”总量E，按当时正射速与默认10模拟秒时长建立N个槽，单发为整数商或多1，余数按carry均匀分散到整个窗口。初始库存1,000,000且相位0时，N=12,000、商83、余数4,000，粒子真实能量为83或84；不是每发始终1能量，也不是末发一次装完余数。补弹重计时，保留射击相位、炮口和目标。

正射速和发完时长的设置即时发送，但在下次真实补弹才锁入新计划，不重排现有弹匣。射速0为立即调试停火，保留库存、相位与计划；恢复正值后已有计划继续，无初始正射速计划时再建立新窗口。E小于N会产生稀疏空槽，不生成零能量实体。物理池满时不扣未发能量，也不推进该能量槽的ordinal/carry；恢复空槽后不爆发补发一截积压子弹。因此停火或背压可使实际发完时间超过名义10模拟秒。

机枪目标切换CD默认0.5模拟秒，锁定身份而非固定角度；有效目标持续追踪，死亡、消失、换代或无法有效攻击时立即重选，不受CD阻挡。防守/附近占地优先级只改变瞄准，不改变固定射频。

当前没有随世界时间增长的发射或占地成本。普通高能粒子、狙击与大球每改变一个非己方格子归属扣1真实能量，余能继续，己方格免费。狙击不会被普通粒子偏转，敌方仍按整数能量抵消；与墙、大球和护盾的物理规则保留。

当前c8已实际完成140项武器/GPU、32项接触、47项设置等[规则回归](../artifacts/validation-1.5.1/rules-area-guard/SUMMARY.json)、20项墙专项、44次性能场景、主场景10项及内嵌PCK运行。PCK短初始窗口实际观察四队各70颗83/84能量粒子，库存994167+在场5833=1,000,000，见[导出证据](../artifacts/validation-1.5.1/export-final/export_pck.json)；这不代表任意战斗无损耗或完整长局已通过。GPU环境是llvmpipe软件Vulkan，实体RTX 5060 Ti和Windows原生未测。

## 历史1.4.1记录

以下是当时1.4.1规则，时间成本、普通一格耗尽和威胁临时加速均不再适用于当前版本。该版本按当时用户要求未启动游戏或运行任何规则、交互、性能、PCK测试；仅源码审阅与构建导出。

- 机枪固定基础射速1200颗/模拟秒，旋转速度1.7弧度/模拟秒，可在参数面板即时调整。时间只提高普通粒子弹药成本，不再提高机枪基础射速。威胁索敌、补附近领土及临时加速保留。
- 每一发按相邻发射间隔计算出生时间；同一物理子步内也有连续不同的炮口角度和实际出生后飞行时长。安全时连续旋转，补地或防守时平滑转向。删除扇形散射和整发补发积压；容量、预算或库存不足时不扣未发出的弹药。每步先服务四队机枪，再发风暴，并为风暴保留一半预算；极高自定义射速触及预算时，已允许的子弹仍均匀分布在整段时间内。
- 普通同色粒子仍实体碰撞；没有为绘制理想曲线关闭物理或伪造命中。高射速下近炮口的实体拥挤仍可能使曲线产生物理变形，尚未经实机观察。
- 狙击只取消与粒子的物理响应：友方粒子直接穿过，敌方粒子抵消能量但双方位置与速度不因这次交互改变。狙击与大球、护盾、墙壁的规则保持原样，不是全场直线穿透。
- 狙击和大球每次真正改变一个非己方格子，都扣占领时的`C(t)=1+floor(max(t-60,0)*0.25)`（可按现有参数调节）。不足时耗尽余量，不改变该格归属；己方格免费。普通粒子仍占一格后消失。
- 出生时刻不同的粒子进行扫掠检测时，从双方均已出生的共同时间开始；出生标记仅在该子步有效，不影响后续正常运动。GPU缓冲区布局保持不变。

旧版配置没有固定射速字段时，从旧末端射速迁移；旧默认1400改为新默认1200，用户自定义末端值保留到新范围。旧射速增长字段仅作兼容别名保存，不再控制游戏。
