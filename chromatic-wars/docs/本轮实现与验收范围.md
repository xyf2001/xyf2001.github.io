# 1.5.0 · 实现与验收范围

本轮明确恢复实际运行、规则回归、性能矩阵和长时间模拟。具体通过项以 `TEST_REPORT.md` 和对应原始日志为准；历史测试不自动代表本轮通过。云端设备为 llvmpipe 软件 Vulkan，任何计时均不能作为 RTX 5060 Ti 实机数据。

## 保留的玩法与新的整数结算

- 所有正式战场状态仍常驻主 RenderingDevice，画面使用共享 Texture2DRD。CPU只处理左侧16球、UI、命令与少量遥测，不逐粒子模拟，也不逐帧读回地图或画面。
- 普通/聚能敌方粒子碰撞按双方64位整数能量的最小值等量抵消，剩余实体沿原方向继续。同阵营普通粒子真实碰撞且不扣能，现有开关保留。狙击与普通粒子不发生物理偏转。
- 普通粒子仍只染一格并耗尽当前剩余能量，先前的敌方粒子抵消不会被重复扣除；狙击与大球逐格扣除当时普通粒子成本。护盾扩张是单独规则，每次实际改变一格归属扣护盾1能量，己方格不扣。
- 大球接触使用碰撞前的质量、速度和法向入射计算反弹与部分损耗。碰撞后不因质量下降重新放大冲量。基础移速由独立、有限加速度驱动补足，不将损耗能量转换为瞬时速度。
- 机枪默认固定1200发/模拟秒。单发能量在补弹时按当前普通成本锁定，期间不随时间自动改值。最后不足一发的库存作为尾发发出，以兼顾整数守恒和正库存不永久停火；这是一项明确的尾数例外。射速0仅用于主动调试停火。转向持续跟随，目标切换CD默认0.5模拟秒；目标失效立即切换，不等待CD。旧存档中的显式合法值保留，不覆盖用户自定义。
- 每次风暴最多1080颗、最多3圈。按输入和成本足以发出360颗时，取不超过该数量的360整倍数，均匀分布每圈；只有不足360颗的低输入允许一圈较稀疏的粒子，避免零能实体。事件总能量用整数商余分配，不因压缩增加或丢弃。容量不足时保留事件进度与库存，实际圈间延迟可因背压而延长。
- 狙击初始第1级，真实墙/敌盾/敌大球接触后，剩余能量的30%向下取整分给子弹，其余70%及余数留给父弹；双方进入下一等级，第3级不再分裂。默认相对真实反射方向左右各8度，可调。普通粒子抵消和领土不触发分裂。无空槽时保留待分裂状态与完整能量，不伪造子弹。
- 护盾缩放参考基准与世界时间解耦；能量不变时不会因世界成长缩小。充能触发从核心向外的同心环扫描；真实扣能或用户修改半径参数仍可改变护盾大小。

## 左侧成长与防卡

每球正常出生仍为2，锁定当时体积门槛。令默认T0=100、目标T*=1,000,000、D=1200模拟秒、τ=1200模拟秒：

`T(t) = T0 * exp(log(T*/T0) * (sqrt(1+t/τ)-1) / (sqrt(1+D/τ)-1))`

该曲线准确通过开局和20分钟目标，连续增长且相对增长率递减。CPU/GPU采用同一公式，单球倍率或保值防卡不刷新出生门槛。浮点映射设有明确的1e30数学安全帽；左侧弹药精确整数上限仍为2^53−1，超过时暂停并保留原值，不能宣称无限期数值增长。

空气墙按真实半径、质量、速度产生连续力与下冲阻力，不按当前全局门槛禁止输出。倍率实体净宽、完整圆进入判定和底墙防逆入保留。修正默认下层柱壁净距不足最大球直径的问题，保留15根可编辑预设柱和用户自定义柱原坐标。静止防卡3模拟秒、局部循环8模拟秒、确认0.4模拟秒；增加当前速度检查，避免确认期末已经恢复运动仍误重发。重发保值并保留出生基准，不算倍率或武器输出。自然防卡频率和热点必须如实记录，不能仅因套件通过就宣称完全无卡球。

## GPU容量与同步

- 新增GPU常驻活跃ID表、普通空闲栈和8个狙击预留槽。物理ID稳定，结束事件后只压紧ID表与回收死亡槽，不搬动粒子实体。
- 移动、建桶、绘制采用GPU生成的间接dispatch，事件与统计只遍历活跃ID，避免大容量空池每子步全扫。正常路径不为读取活跃数量增加CPU/GPU同步。
- binding10：每队128B武器状态，共512B；binding11：16字头+容量个活跃ID+容量个空闲ID；binding12：间接调度参数和可选诊断，共128B。原有Particle64B和Team128B布局保留。
- 完整空间链、九色调度、唯一配对、高速回退和大球粗网格均保留。不限制密集桶候选数量，因此极高局部密度仍有真实的二次碰撞成本。
- GPU阶段计时、实际绘制FPS、完成步吞吐分别记录。异步完成延迟包含排队与帧调度，不称为阻塞同步等待；分配字节不是已测物理显存驻留。

## 需要披露的边界

狙击在极端人为重叠实体里单子步最多处理72次连续接触，触顶停在最后合法位置以避免零TOI死循环；不能把这项保护称为无限接触的完整解析。正常子步是否触顶以测试记录为准。软件设备长局或压力测试若未达到目标时间，必须记录实际时长并标为未完成；不能缩小地图、删除碰撞或套用旧版测试冒充默认配置通过。
