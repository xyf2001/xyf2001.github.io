# 1.4.2 恒速与最低移速

本轮按用户要求未运行游戏或测试，只做源码静态审阅和构建导出。

普通粒子原先使用等质量弹性速度交换，该规则守恒两颗的总动能，不能保证每颗速度不变。例如正交等速的粒子在合适法线碰撞下，一颗会停下，另一颗加速。默认1200发/秒、速度140、物理直径2.4时，连续弹丸出生间距远小于直径，密集同色接触会频繁遇到这类结果。

本版每颗小粒子保留出生速率，碰撞先求出方向，再恢复本身的速率。零速度退化解改为沿接触法线离开。该规则为用户要求的恒速运动，不是严格的逐次机械动量守恒；弹药整数账本不因此增加或扣除。狙击与普通粒子仍只做敌方能量抵消、友方穿行。

墙壁原先只在移动时处理，后续碰撞位置投影又能把对象挤出边界。本版在普通粒子和大球投影后补墙约束，反射朝墙外的速度，并在盾/球事件后再次约束。墙反射不扣普通粒子速率。

大球新增“最低移速”，默认40px/s，可在参数中即时修改，且不超过“发射速度”。大球仍按质量与软硬碰撞、被弹丸推动和消耗。移动前、墙反射后及整步碰撞/推动结算后不足最低速度时补足，保留已有方向；精确抵消到零时采用最近有效航向。最近航向存入现有next缓冲区的大球尾部，无新增GPU缓冲或CPU粒子回读。

普通粒子首次染到一个非己方格子后消失，该路径没有因当前成本上涨而拒绝旧粒子。512²地图的一格只有2×2世界单位；成本增长还会减少同等弹药可发出的粒数。因此占地较慢既可能受到停弹影响，也包含现行经济规则。本版保留一粒一格及当前每格成本。

非零速率能够防止速度衰减到零，但不能保证任何密集布局都没有几何拥挤或抖动。新版尚未经运行观察，不承诺具体FPS或全部堆积情形均已消除。
