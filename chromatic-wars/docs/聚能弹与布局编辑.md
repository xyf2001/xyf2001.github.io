# 1.3.0-sandbox 实现说明

本轮按用户要求未运行测试，仅构建导出。

- 狙击接收一次命令后保留64位能量并蓄能，到期将全部能量发成一颗type2粒子。速度取sniper_speed，蓄能时长取sniper_charge_time。没有光束射线结算。
- 普通粒子槽尾部8个预留给聚能弹，普通发射遍历前cap-8；聚能弹从尾部开始寻找全部cap个槽。容量不足保留库存。
- 聚能弹使用短胶囊拖尾与白热颜色，实际碰撞半径仍与普通粒子一致，避免视觉光晕改变碰撞格约束。高能弹不计入普通能量包近似比例。
- head缓冲扩为4×128²个int；build_space按team×cols²+cell建链，九色phase只遍历敌方链。当前粒子耗尽后立即停止后续候选遍历。
- Parameters仍为64floats：块10/11存四队XY坐标；块12.xy是护盾最大半径和狙击蓄能时长。盾宽UI以直径输入。
- 基地位置仅初始化读取；盾上限与蓄能时长可即时更新参数。面积初始化仍为四象限25%。
- 布局三档净宽左右镜像，总和最多158，中央至少84；可调隔板与底墙使用同一cuts数据。底墙保持子步来源侧并在球球位置投影后再次约束。
- custom_pegs为Array[Vector3]，Vector3=(x,y,r)。主控提供暂停放置/右键删除/清空、预览并自动保存；默认柱保留。设置和界面同步，避免后续参数编辑覆盖刚放置的柱。
- 流畅预设需显式点击并新开局，采用256²地图/512²渲染/关闭普通拖尾，保留精确模式、容量和全部粒子显示。
