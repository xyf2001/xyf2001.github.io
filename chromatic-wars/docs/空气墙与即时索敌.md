# 1.4.3-air-aim · 空气墙、即时索敌与单位

本版本按用户要求未运行游戏或测试；导入和Windows导出只用于生成交付文件。

## 左侧未长大小球过早下落

原先半径按各球出生时锁定的门槛T计算，机械质量的弹药项却按初始100计算。后期出生的2048球仍是小球，却获得过大的质量，空气上托可能已经小于重力。

现在令q=E/T、g=log(1+max(q−1,0))、a=log(1+E/max(100,T_start))，使用有界因子`0.9*g/(6+g)+0.1*a/(6+a)`计算机械质量与软硬，主要跟随球本身的成长；精确弹药E独立保留。空气墙使用圆形轮廓覆盖范围，上升气流对下冲球增加速度平方阻力；额外阻力随q从1到4平滑退去，且每子步限制阻力冲量，避免数值反转。关闭空气推力也会关闭额外阻力。

保留每球出生门槛、正常输出重置为2和采用新门槛的规则。早期出生的2048球可能已经长大，数值不同本身不是错误。空气墙为有限推力，不是不可穿越实体墙；极端撞击或人为弱化气流仍可能让球落下。

## 防卡与机枪

防卡每0.1模拟秒采样，静止窗口3、局部循环窗口8、持续确认0.4、重发冷却1模拟秒。观察实际逐子步路程、覆盖区域和最深进展；重发保留阵营、数值和出生门槛，不触发倍率、输出或武器。

机枪取消角度保持窗口，每个有弹药的模拟子步重新判定。空间建桶时并行摘要近身敌方弹丸，下一子步只复核两条弹丸候选，同时保留大球威胁和附近占地查询。保留连续逐发角度与有限转向速度，转向速度使用弧度/模拟秒。新增归约有额外GPU成本，尚无实测帧率结论。

## 单位和碰撞开关

- 所有物理坐标、宽高、半径和直径统一为游戏单位；速度用游戏单位/模拟秒，加速度用游戏单位/模拟秒²。右侧场地1024×1024游戏单位，窗口缩放不改变物理尺寸。
- 游戏计时使用模拟秒，暂停时停止；0.25倍速下3模拟秒约需12真实秒，若模拟积压则更久。渲染分辨率为像素、领土精度为格数，FPS/GPU耗时仍为真实设备测量。
- 打开参数面板，在「04 GPU性能与画面」切换「同阵营普通粒子碰撞」，即时生效，默认开启。可用保存/加载留存设置。关闭时跳过同色普通粒子碰撞，同色大球碰撞、己方粒子吸收入大球、敌方结算、狙击的粒子穿透规则保持原有行为。
